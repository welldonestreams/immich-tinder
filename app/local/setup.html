Immich Tinder — Setup

Connect the app to your Immich photo library.

You need two things from your Immich server — both take under a minute: 1. the server address   2. an API key.

This is the address you use to open Immich in your browser. If you don't know it, ask whoever runs the server (or find it in your Immich app: Settings → Server Information).

Where to get it: log into your Immich server (open it →), click your avatar → Account Settings → API Keys → New API Key.

Still stuck?
  1. Server URL — the same web address you type to reach Immich (example: https://immich.example.com).
  2. API key — in Immich: avatar (top-right) → Account Settings → API Keys → New API Key → copy it. It looks like a long random string.
  3. Paste both above and hit Save. Done — the app opens.
